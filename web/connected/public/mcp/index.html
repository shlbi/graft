02 / PRODUCTION BOUNDARIES

Powerful.
Deliberate.

01

No bearer-token passthrough. MCP access tokens authorize Repot. GitHub tokens remain server-side and are obtained through the user's linked GitHub account.

02

Reviews expire and are encrypted at rest. A publish call must reference an exact unexpired review owned by the authenticated user.

03

The default branch is never written. Publication creates a new repot/* branch and a draft pull request, and refuses a destination that changed after review.

04

Verification is never invented. Repot does not execute generated repository code in the MCP service. Build, tests, and integration remain not_run until an isolated verifier actually runs them.
